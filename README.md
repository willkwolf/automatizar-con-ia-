## 🎯 Propuesta de Valor: Aprende Construyendo

Boutique Digital transforma la inteligencia artificial en una capacidad operativa demostrable. No vendemos teoría sobre IA ni certificados de asistencia vacíos; capacitamos a personas sin conocimientos previos de programación para ensurciarse las manos, estructurar, construir y supervisar flujos de trabajo funcionales que ahorran horas de trabajo manual.

### La Progresión de Madurez:
```
USUARIO BÁSICO ──► OPERADOR DE IA ──► CONSTRUCTOR (BUILDER) ──► CONSTRUCTOR AUTÓNOMO
```

## 📚 Arquitectura del Programa (5 Semanas · 5 Entregables)

1. **Semana 1 · Asistentes con Contexto Persistente:** Meta-prompting, políticas operativas y asistentes consultivos adaptados al nicho del alumno.
2. **Semana 2 · Entorno de Trabajo y Consulta Documental:** Bases de conocimiento estructuradas con NotebookLM y producción de síntesis ejecutivas con fuentes oficiales.
3. **Semana 3 · Automatización de Tareas Reales:** Flujos determinísticos con Make / n8n, disparadores automáticos y manejo de excepciones.
4. **Semana 4 · Constructor de Miniaplicaciones Web:** Desarrollo en lenguaje natural (Stitch, Lovable, Antigravity) para desplegar calculadoras y portales interactivos.
5. **Semana 5 · Chatbots Comerciales y Supervisión:** Asistentes conversacionales 24/7 para WhatsApp y web con protocolo estricto *Human-in-the-Loop*.
